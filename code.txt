## 1. Backend: [backend/main.py](file:///c:/Users/ayush/OneDrive/Desktop/Slope-Sentinel/backend/main.py)
> **Role:** The **"Brain and Engine"** of the project.  
> It does the math, calculates landslide risk, stores monitored zone data, and sends information to the browser.

### Key Sections in this file:

#### A. Setup & App Initialization (Lines 1–25)
* **What it does:** Imports FastAPI, sets up CORS (Cross-Origin Resource Sharing), and configures the app.
* **Role:** Allows the frontend webpage to securely communicate with the Python backend without getting blocked by browser security restrictions.

#### B. The Input Data Schema: `RiskRequest` (Lines 27–34)
```python
class RiskRequest(BaseModel):
    rainfall: float = Field(128, ge=0)
    soil_moisture: float = Field(74, ge=0, le=100)
    slope: float = Field(38, ge=0, le=90)
    deformation: float = Field(7.2, ge=0)
    historical_events: int = Field(4, ge=0)
    data_reliability: float = Field(91, ge=0, le=100)
```
* **What it does:** Uses **Pydantic** to define the exact rules for what inputs the AI predictor needs (e.g., rainfall cannot be negative; soil moisture must be between 0 and 100%).
* **Role:** Protects the backend from bad or corrupted inputs.

#### C. The AI Risk Calculation Engine: `risk_score()` (Lines 35–52)
```python
def risk_score(x: RiskRequest):
    rainfall = min(x.rainfall / 180, 1) * 28
    soil = x.soil_moisture / 100 * 20
    slope = min(x.slope / 55, 1) * 18
    deformation = min(x.deformation / 15, 1) * 20
    history = min(x.historical_events / 8, 1) * 9
    raw = rainfall + soil + slope + deformation + history
    confidence = max(42, min(99, 58 + x.data_reliability * .38 - abs(85 - x.data_reliability) * .12))
```
* **What it does:** 
  1. Multiplies each environmental factor by its scientific weight (Rainfall = 28%, Soil = 20%, Ground Shift = 20%, Slope = 18%, Past Slides = 9%).
  2. Calculates the **Risk Score** (0 to 100).
  3. Classifies it into a threat category: **CRITICAL** ($\ge 70$), **HIGH** ($\ge 52$), **MODERATE** ($\ge 32$), or **LOW**.
  4. Computes a **Confidence %** based on sensor health.
* **Role:** This is the core decision-making algorithm that decides if a slope is safe or about to fail.

#### D. REST API Endpoints (Lines 53–131)
* **`/api/health`**: Reports if the server is running properly.
* **`/api/overview`**: Sends overall numbers for the top dashboard cards (e.g., 18 active zones, 3 critical, 98.6% uptime).
* **`/api/zones`**: Sends the list of monitored locations in Northeast India (Aizawl, Gangtok, Kohima, Tawang, Shillong, Imphal, etc.) with coordinates and danger levels.
* **`/api/alerts`**: Sends the recent incident alerts feed.
* **`/api/pipeline` & `/api/references`**: Sends the architecture steps and official sources (NDMA, ESA, GSI, IMD).
* **`/api/predict`**: Accepts the slider numbers from the user, runs `risk_score()`, and sends back the score, risk level, confidence, and action advice (e.g., *"Immediate alert and evacuation readiness"*).

#### E. Serving the Frontend (Lines 133–138)
```python
app.mount("/app", StaticFiles(directory=str(BASE / "frontend"), html=True), name="frontend")
@app.get("/")
def root():
    return FileResponse(BASE / "frontend" / "index.html")
```
* **What it does:** Hosts the HTML, CSS, and JS directly from Python so the entire project runs as **one single integrated program** on `http://127.0.0.1:8000`.

## 3. Frontend Logic: [frontend/assets/app.js](file:///c:/Users/ayush/OneDrive/Desktop/Slope-Sentinel/frontend/assets/app.js)
> **Role:** The **"Nervous System"** of the frontend.  
> It handles clicks, fetches data from the backend, updates the UI in real time, and controls animations.

### Key Functions in this file:

* **`api(path, options)` (Lines 4–8):**
  * Helper function that uses JavaScript's `fetch()` to call the Python backend and convert the reply into usable JSON objects.
* **`showView(id)` (Lines 9–16):**
  * Switches between the 7 tabs without reloading the page. It hides the previous view and reveals the chosen one smoothly.
* **`sync(el, id, suffix)` (Line 18):**
  * When you drag a slider (e.g., rainfall), this immediately updates the number next to it in real time (e.g., `128 mm`).
* **`load()` (Lines 21–29):**
  * Runs automatically the moment the page opens. It calls `Promise.all` to fetch all data from `/api/overview`, `/api/zones`, `/api/alerts`, etc., in parallel and paints the screen with live information.
* **`renderMiniMap()` & `renderBigMap()` (Lines 31–36):**
  * Generates the SVG map graphic and calculates where to position each blinking colored pin for Aizawl, Gangtok, Kohima, etc.
* **`col(l)` (Line 37):**
  * Returns the right color code: `#ff5577` (Red for Critical), `#ff914d` (Orange for High), `#ffc857` (Yellow for Moderate), or `#6fffb0` (Mint Green for Low).
* **`predict()` (Lines 44–51):**
  * When you click **"RUN AI PREDICTION"**:
    1. Grabs the values from all 6 sliders.
    2. Packages them into a JSON payload.
    3. Sends a `POST` request to `/api/predict`.
    4. Updates the circular score ring, changes the badge color, animates the confidence bar, and prints the recommended safety action.
